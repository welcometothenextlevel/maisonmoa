# Maison Môa — institut de beauté, Riaz

Site vitrine statique (FR) pour Maison Môa, institut de beauté à Riaz, près de Bulle.

- Pages générées par `python3 _build/build.py` (contenu dans `_build/content.py`, prix et descriptions repris de Salonkee).
- 3D : `assets/js/scenes.js` (three.js r170, scènes modélisées en code, une par univers de soins).
- Animations : GSAP + ScrollTrigger + Lenis (`assets/js/site.js`).
- Réservation : Salonkee ; formulaires sans serveur (WhatsApp / e-mail pré-remplis).
- Page en `noindex` tant que le site n’est pas sur maisonmoa.ch.
